# Cheat-messenger
We made this messenger for easy cheating on olympiadas in school. It was made in three evenings. Not for work longer than few hours. You should never use request spam to check for messages. It will never be finished.
You can freely use this for your projects, but vibe coding is better.
## Installation
You should not install this, but if you really want to, you can. But it probably won't run.
1. Install http/https server of your choice.
2. Copy html/css/js files into http server's root folder or if not root edit html files, except api.js
3. Edit script.js to properly work with your domain or ip
4. Install highlight.js by downloading highlight.min.js into http root folder
5. Install node js and express js and run api.js
6. Configure http server to properly handle /api requests.
7. Test if you need to do anything.
